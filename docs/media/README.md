Screenshots and the full recording use a 1440 × 960 viewport. The animated preview is 960 × 640. The README displays all media at a consistent width of 960 pixels, capped by the available width in GitHub's renderer. Images preserve their aspect ratio and link to the original files. Additional screenshots belong in collapsible sections so the main page stays readable.

To refresh the assets, enter **Try the demo**, skip the guided tour, and capture the same screens after they finish loading. Keep the demo banner visible. Record navigation only, without editing shared data or running paid AI tasks. Never capture a personal account, provider credentials, worker pairing codes, or inbox content.

Capture files temporarily under `output/playwright/`, then copy only the reviewed images and recording into this directory. Browser snapshots, session storage, traces, and intermediate frames do not belong in the repository.
